The finding

Fine-tuning on the app contract lifts Gemma-4 but not Qwen3

Five models, two on-device families plus one hosted frontier anchor: Gemma-4 E4B and Qwen3-8B each run as a shipping/candidate base and as an app-contract fine-tune, and gpt-5 calibrates the ceiling on the same 593 cases. The clearest result is Aave and Safe — protocols the shipping model never saw.

Gemma-4 E4B base here is not an untuned model — it's the exact Q4_K_M GGUF local-wallet-mac ships today, a fine-tune from an earlier round that only ever learned transfer, swap and RAILGUN shield/unshield. Scored against the app's own contract across all 593 cases, it passes 405 (68.3%).

Split that by what it was trained on and the shape sharpens. On the 397 cases that existed in some form before — transfer, swap, the arithmetic slice, multi-turn, ablations, refusals, RAILGUN — it already scores 88.2% (350/397). On the 196 Aave and Safe cases, protocol families it has never been trained to call, it scores 0%: 0/90 on Aave, 0/50 on Safe.

The app-contract fine-tune closes almost all of that gap. Re-tuned on the same recipe with Aave and Safe added to the curriculum, it takes the familiar 397 cases to 98.0% (389/397) and the new 196 to 75.0% (147/196) — RAILGUN 56/56, Aave 42/90, Safe 49/50. Overall: 536/593 (90.4%).

A second, larger on-device family — Qwen3-8B — tells a different story. Its base model, hosted via OpenRouter at the card's recommended sampling, is already strong zero-shot at 87.9% (521/593), including 40/90 on Aave and 48/50 on Safe without ever training on this contract. Re-tuning it on the same app-contract data — run locally, same Q4_K_M quantisation as the Gemma-4 comparison — does not repeat the Gemma-4 lift: the fine-tune scores 86.3% (512/593), slightly below its own base.

gpt-5, the hosted frontier anchor, tops the field at 96.5% (572/593) — every one of the 90 Aave cases, all but one of 50 Safe, and 52/56 on RAILGUN. All five strips above and the breakdown table below are the same 593 cases, scored by the same deterministic scorer.

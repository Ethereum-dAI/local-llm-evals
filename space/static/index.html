Headline

What the fine-tune bought

The finding

The base model you start from sets the ceiling

The strips come in pairs: each fine-tune sits directly under the model it was trained from, on the same 1739 synthetic rows with the same LoRA recipe. Both pairs move a long way. They do not land in the same place, and the ordering of the two fine-tunes is the ordering of the two bases.

Same data, same recipe, different starting point. Gemma-4 E4B goes 12.7% → 80.1% (+67.4 pp). Qwen3-8B goes 41.0% → 86.0% (+45.0 pp). The weaker base gains far more and still finishes behind.

So the training set is not the binding constraint — the same rows are enough to teach both models the task. What separates the two results is the capability each one brought with it, most of it base-unit arithmetic.

Both fine-tunes remain weak in the same place: safety refusals, 5 of 7. The training set contains roughly one example per refusal category out of 1739 rows, which is the likely cause and a cheap fix.

Two things that are not held constant, stated rather than buried. Each model runs at its own card's sampling — Qwen3 at 0.6/0.95/20 (its card forbids greedy decoding), Gemma-4 at 0.2, gpt-5 at 0.1 — because a low score from settings the authors warned against measures nothing. And the Qwen3 base column is hosted at full precision while its fine-tune is a Q4_K_M file running on-device; quantization costs a few points rather than adding them, so that pairing understates the gain rather than inventing it.

Sanity check

The E4B fine-tune did not trade away general capability

Training a model for one narrow skill invites the obvious objection: it got better at wallet calls by getting worse at everything else. It did not. Across six standard benchmarks nothing collapses: MMLU is 4.4 points higher after fine-tuning, TruthfulQA 2.2 lower, and the other four move by about a point or less. So the jump above is a skill that was added, not traded for.

The Q4_K_M columns are the quantized builds that actually run on-device. Quantization costs between 1 and 4.6 points depending on the benchmark, and costs both models about the same, so it does not disturb the base-vs-fine-tune comparison either.

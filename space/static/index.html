Wallet tool-call benchmark

1000 natural-language requests, scored on whether a model emits the exact transfer/swap call a macOS Ethereum wallet would execute. The contract is the app's own: human decimal amounts (50.25 USDC, not base units), a token symbol, and the recipient copied verbatim — the model does not resolve ENS.

571 cases are multi-round conversations (2–6 turns) testing which turn's value should win. 80 are an arithmetic slice. 120 have no correct call at all, 49 of them adversarial refusals — so a headline percentage alone is not capability.

The fine-tune the wallet shipped scored 21.7 points below the untuned base. Its card claimed 80.1%, measured on a retired benchmark whose amounts were base units. The app's contract moved to human decimals and nobody re-measured. 266 of the 880 cases that wanted a call got prose instead: declining an under-specified amount was correct under the contract it trained on.

ft-v5's gain is one bucket. “Expected a call, produced none” went 45 → 1. An act-not-ask clause, retry-on-no-call and few-shot exemplars all failed to move it, and gpt-5 has 51. Spurious calls fell 24 → 9 in the same pass, so it did not simply learn to always act.

The refusal win is the prompt, not the fine-tune. ft-v5's 47/49 against gpt-5's 34/49 looked like a model difference; gpt-5 had never seen the clause. Given the same system turn it also scores 47/49. Refusal accuracy with the clause vs without: base 91.8%/61.2%, ft-v5 95.9%/81.6%, gpt-5 95.9%/69.4%.

Residual failures differ in kind. gpt-5 + clause makes zero wrong-argument errors in 1000 cases — its whole residual is 63 decisions. ft-v5's is the mirror: 35 wrong arguments, 12 no-calls. Deciding whether and what to call is where a 4B model has caught up; copying a long literal is where it has not. malformed-address is 3/3 for gpt-5 and 1/3 for ft-v5 + clause, which is an argument for validating address format in the app rather than in the prompt.

Discard differences under about six cases. Three runs of the same ft-v5 GGUF on different rented GPUs scored 949, 952 and 944; base reads 903 in one run and 908 in another. The three clause-off columns come from a single run so that comparison is device-controlled; each clause-on column comes from its own paired A/B with both arms on one GPU.
